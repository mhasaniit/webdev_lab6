# Web Development Lab 6

## Overview
This is Lab 6 for ITMD-361. In this lab, I worked on optimizing HTML and CSS code to improve structure, readability, and overall design quality. The focus was on refining existing code rather than building from scratch.

## Features
- Optimized HTML structure for better organization
- Improved CSS styling for cleaner and more consistent design
- Enhanced readability and maintainability of code
- Applied best practices for web development formatting

## Tools Used
- HTML5
- CSS3
- Visual Studio Code
- GitHub (for version control and submission)

## Learning Outcomes
- Learned how to improve and refine existing HTML/CSS code
- Strengthened understanding of clean code practices
- Improved ability to work with both structure (HTML) and styling (CSS)
- Gained experience in optimizing web page layout and design

## Purpose
The purpose of this lab was to develop skills in optimizing and improving web pages by refining both structure and styling using HTML and CSS.
